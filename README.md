# Blathers
An offline, handmade ACNL museum tracker for the 3DS

## Roadmap:

### 0.1.xx:
- Implement basic UI via LOVE
- View a small selection of animals in a grid layout
- Display information on the selected animal (likely lifted from Nookipedia, with attribution)

### 0.2.xx:
- Basic images and descriptions for all fish, bugs, sea creatures, and art
- Add touch screen support

### 0.3.xx:
- Allow the user to import an unencrypted save file from checkpoint
- Show which items have been donated based on the information in the save file

### 0.4.xx:
- Read and handle save files automatically, directly from the console
- Also show which items have been discovered but not donated

### 0.5.xx & 0.6.xx (order determined later):
- Clean up UI
- Add options menu to allow users to hide or show information (ie. hide all items that haven't been discovered yet, only show detailed info for items that have been discovered, etc.)
- Add additional information to all animals (season, active times, etc)
- Add images of fake art for comparison

### 1.0:
- Cleanest UI
- Add sound effects
- Works on Old and New 3DS systems
- Supports both pre- and post- Welcome Amiibo saves
- Full touchscreen support
- Few to no bugs
- Maybe more stuff idk
